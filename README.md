# 3i Robot Vacuum — интеграция для Home Assistant

Неофициальная интеграция роботов-пылесосов **3i** (P10 Ultra и других моделей
экосистемы 3irobotix / Picea) в Home Assistant: управление уборкой, статус,
батарея, базовая станция, ресурс расходников, уровень воды, уборка по комнатам.

Работает через официальное облако 3i: HTTP-авторизация + MQTT (TLS, порт 8883).
Локального доступа к роботу нет — нужен интернет и аккаунт 3i Home.

---

## ⚠️ Важно прочитать

- Интеграция **не является продуктом 3i / Picea** и использует неофициальный
  облачный API. Он может измениться или перестать работать в любой момент.
- Пароль от аккаунта 3i сохраняется в настройках интеграции Home Assistant
  (`.storage/core.config_entries`) — как и у большинства других интеграций.
  HA не шифрует этот файл: он виден в резервных копиях. Не добавляй интеграцию
  на инстанс HA, к которому есть доступ у посторонних.
- Один аккаунт 3i = один робот = одна запись интеграции.

## Поддерживается

| Модель | Статус |
|---|---|
| 3i P10 Ultra | проверено автором |
| Другие модели 3irobotix / Picea | вероятно работают, не проверено |

Сущности: `vacuum` (старт / пауза / стоп / возврат на базу / режим всасывания /
`send_command`), сенсоры (батарея, статус станции, код ошибки, площадь и время
уборки, Wi-Fi, 4 расходника, версия прошивки), `select` уровня воды,
`button` уборки отдельных комнат.

## Установка

### Вручную

1. Скачай последний release, распакуй папку `three_i` в
   `<config>/custom_components/three_i`.
2. Перезапусти Home Assistant.
3. Настройки → Устройства → **Добавить интеграцию** → «3i Robot Vacuum».

### Через HACS

1. HACS → Integrations → ⋮ → Custom repositories.
2. Type: `Integration`, Repository: `https://github.com/suxobludov/ha-three_i`,
   добавить.
3. Найти «3i Robot Vacuum» → Install → перезапустить HA.

## Настройка

При добавлении запрашиваются три поля:

| Поле | Откуда взять |
|---|---|
| Логин | почта или телефон аккаунта 3i Home |
| Пароль | пароль от этого аккаунта |
| Серийный номер | наклейка на дне робота, формат вида `P10UJPxxxxxxxxx`; также в приложении 3i Home в сведениях об устройстве |

Логин и пароль проверяются реальным входом в облако: если облако отклоняет
данные, интеграция не создастся и покажет ошибку.

Серийный номер — это и есть `device_id` в топиках MQTT, поэтому он обязателен.

### Комнаты

Кнопки «Уборка комнаты N» создаются по списку ID комнат, который ты задаёшь сам:
Настройки → Устройства → 3i → **Настройки** → «ID комнат».

ID комнат специфичны для твоей карты робота, у каждого они свои. Как получить:
в приложении 3i Home посмотри порядок комнат на карте, затем сверь по атрибутам
сущности пылесоса в HA (`developer tools → states → vacuum.3i_p10_ultra`), либо
по дампу MQTT-топиков карты. Если поле оставить пустым — кнопки не создаются,
остальная функциональность работает.

### Примеры `send_command`

```yaml
# Уборка конкретных комнат
service: vacuum.send_command
data:
  entity_id: vacuum.3i_p10_ultra
  command: clean_rooms
  params:
    room_ids: [10, 16]

# Уровень воды: 1 низкий, 2 средний, 3 высокий
service: vacuum.send_command
data:
  entity_id: vacuum.3i_p10_ultra
  command: set_water_level
  params:
    water: 2

# Любая служба облака 3i напрямую
service: vacuum.send_command
data:
  entity_id: vacuum.3i_p10_ultra
  command: start_recharge
```

## Ресурс расходников

Робот сообщает **отработанные часы**, проценты считаются от полного ресурса:
основная щётка 360 ч, боковая щётка 180 ч, HEPA 180 ч, мопы 300 ч.
Значения задаются в `const.py` (`CONSUMABLE_MAX_HOURS`) — если у твоей модели
ресурс другой, поправь там.

## Диагностика

Лог ищется по префиксу `3i`. Частые симптомы:

| Симптом | Причина |
|---|---|
| «Облако 3i отклонило логин» | данные от другого приложения (ILIFE и т.п.) или регион не `cn` |
| Робот `unavailable` после перезапуска | облако недоступно, HA повторит подключение сам |
| Сенсоры пустые | робот присылает только изменения; полный опрос идёт при подключении и каждые 5 минут |
| MQTT-топик не тот | неверный серийный номер |

## Ограничения

- Камера робота не поддерживается (видео идёт через Agora RTC, отдельная цепочка
  авторизации).
- Карта помещения и зоны/виртуальные стены не доступны.
- Регион: проверено на китайском кластере (`cn-appaiot.3irobotix.net`). Для
  других регионов поправь хосты в `const.py`.
